YT Downloads
Este é um projeto simples e eficiente projetado para facilitar o download de vídeos e a extração de transcrições do YouTube.

🚀 Funcionalidades
Baixar Vídeos: Faça o download de vídeos do YouTube diretamente para o seu computador.

Extrair Transcrições: Obtenha o texto das legendas/transcrições de vídeos do YouTube de forma automatizada.

🛠️ Pré-requisitos
Antes de começar, certifique-se de ter instalado em sua máquina:

Python 3.x: (Recomendado versão 3.8 ou superior).

Pip: O gerenciador de pacotes do Python.

📝 Como configurar e utilizar
Siga estes passos didáticos para colocar o projeto em funcionamento:

1. Clonar o repositório
Abra o seu terminal (ou prompt de comando) e clone o repositório:

Bash
git clone <url-do-repositorio>
cd yt-downloads
2. Instalar as dependências
Para que os scripts funcionem, precisamos instalar as bibliotecas necessárias. Execute o comando abaixo na pasta do projeto:

Bash
pip install -r requirements.txt
3. Utilizando os scripts
Para baixar vídeos
Execute o script baixar_videos.py seguindo as instruções dentro do arquivo (ou passando o link do vídeo como argumento, conforme implementado no código):

Bash
python baixar_videos.py
Para baixar transcrições
Execute o script baixar_trancricao.py:

Bash
python baixar_trancricao.py
💡 Observações Importantes
Certifique-se de estar com uma conexão estável com a internet.

Alguns vídeos podem ter restrições de idade ou serem privados, o que pode impedir o download ou a extração de transcrição.
